# Unit Test Evidence

This folder contains the test outputs for the Library Book and Seat Reservation
application.

## Flutter

- `flutter/` contains one output file for each test file.
- `flutter/coverage/` contains the coverage output generated by Flutter.

## Backend

- `backend/` contains the Maven test output and Surefire reports.

The commands used to generate the evidence were:

```powershell
flutter test
flutter test --coverage
.\mvnw.cmd test
```

Upload this `test-evidence` folder to Google Drive after reviewing the results.
